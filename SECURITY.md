# Security

This MCP server is intended to run locally over standard input/output with a trusted client. It can modify stored presets and read or create preset files using paths supplied by the client.

Review client tool permissions, confirm writes and keep backups of important presets. Avoid exposing the server to untrusted clients or network access.

Report security issues privately to the repository maintainer, using GitHub private vulnerability reporting when enabled. Avoid posting exploit details, personal data or credentials in public issues.
