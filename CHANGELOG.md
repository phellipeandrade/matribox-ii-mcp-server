# Changelog

## 0.1.0

Initial public release.

- Local MCP server for the Sonicake Matribox II on Windows.
- Preset browsing, reading, selection, creation, copying, renaming, import, export and restoration.
- Effect catalog inspection, model changes, parameter editing and bypass.
- Standard single-preset .prst codec with integrity checks.
- Offline tests and documented USB MIDI protocol.
